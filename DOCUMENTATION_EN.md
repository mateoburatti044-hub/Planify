## 🚀 Getting Started

### Installation
```bash
npm install
npm run dev
```

### Running Tests
```bash
# Interactive GUI
npx cypress open

# Headless
npm run test:e2e

# Specific browser
npx cypress run --browser chrome
npx cypress run --browser firefox
npx cypress run --browser safari
npx cypress run --browser edge

# BrowserStack (4 browsers)
npm run test:browserstack
```
