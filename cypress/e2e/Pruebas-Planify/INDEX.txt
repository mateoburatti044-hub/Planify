🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problema: npm install falla
Solución: Asegúrate de tener Node.js instalado
         npm --version

Problema: Port 5173 ya está en uso
Solución: npm run dev -- --port 5174

Problema: Tests no funcionan
Solución: Verifica que npm run dev está ejecutándose
         Abre http://localhost:5173 en el navegador

Problema: Datos no se guardan
Solución: Comprueba que IndexedDB está habilitado en el navegador
         Abre DevTools > Application > IndexedDB
