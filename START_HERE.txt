💡 TIPS IMPORTANTES

1. Los datos se guardan AUTOMÁTICAMENTE
   └─ No necesitas hacer nada especial, funciona de fondo

2. Puedes usar cualquier contraseña en login
   └─ Es un sistema mock, no hay validación real

3. Los datos persisten incluso si:
   └─ Cierras el navegador
   └─ Actualizas el código
   └─ Refrescas la página (F5)
   └─ Cambias de tab

4. Puedes hacer backup manual en Settings
   └─ Settings (⚙️) → Persistencia & Backup → Descargar Backup

5. Ver datos en Storage
   └─ F12 → Application → Local Storage → planify_backup
